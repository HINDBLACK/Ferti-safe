# FERTI SAFE — موقع الكتالوج الزراعي

موقع Next.js 14 (TypeScript + Tailwind + Supabase) لعرض منتجات FERTI SAFE بثلاث لغات
(عربي RTL / فرنسي / إنجليزي)، مع لوحة تحكم كاملة لإدارة المنتجات، الصور، الفئات،
الترجمة، وإعدادات الشركة — دون الحاجة لمس الكود.

> ملاحظة صراحة: بُني هذا المشروع في بيئة عمل بدون اتصال إنترنت، لذلك لم يكن بالإمكان
> تشغيل `npm install` أو تجربة البناء فعليًا هنا. الكود مكتوب ومُراجَع بعناية، لكن
> يُنصح باختبار محلي (`npm run dev`) قبل النشر النهائي، ومراسلتي إن ظهر أي خطأ لتصحيحه.

---

## 1. المتطلبات

- Node.js 18.18 أو أحدث
- حساب [Supabase](https://supabase.com) مجاني
- (اختياري لكن مطلوب لتفعيل الترجمة التلقائية) مفتاح API من [console.anthropic.com](https://console.anthropic.com)

---

## 2. إعداد قاعدة البيانات (Supabase)

1. أنشئ مشروعًا جديدًا في Supabase.
2. اذهب إلى **SQL Editor > New query**، الصق محتوى ملف `supabase/schema.sql` بالكامل واضغط **Run**.
   هذا ينشئ كل الجداول، RLS، وحاوية تخزين الصور `product-images`.
3. افتح استعلامًا جديدًا آخر، الصق محتوى `supabase/seed.sql` واضغط **Run**.
   هذا يملأ قاعدة البيانات بالفئات الست و61 منتجًا حقيقيًا (بأوصاف معاد صياغتها،
   بدون صور — ستضيفها أنت من لوحة التحكم).
4. من **Authentication > Users > Add user**، أنشئ مستخدم الأدمن (بريد إلكتروني
   وكلمة مرور) الذي ستسجّل به الدخول للوحة التحكم على `/admin/login`.

---

## 3. متغيرات البيئة

انسخ `.env.example` إلى `.env.local` واملأ القيم:

- `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY`: من
  **Project Settings > API** في Supabase.
- `SUPABASE_SERVICE_ROLE_KEY`: من نفس الصفحة (احتياطي لتوسعات مستقبلية، غير
  مستخدم حاليًا في الكود لأن لوحة التحكم تعتمد على RLS + جلسة الأدمن مباشرة).
- `ANTHROPIC_API_KEY`: لتفعيل زر "ترجمة تلقائية بالذكاء الاصطناعي" في لوحة
  التحكم. بدونه، الزر سيعرض رسالة خطأ واضحة، ويمكنك حينها كتابة كل لغة يدويًا.

---

## 4. التشغيل محليًا

```bash
npm install
npm run dev
```

افتح `http://localhost:3000` (يحوّلك تلقائيًا إلى `/ar`)، ولوحة التحكم على
`http://localhost:3000/admin/login`.

---

## 5. النشر (Vercel — الأسهل)

1. ارفع المشروع إلى مستودع GitHub.
2. من [vercel.com](https://vercel.com)، استورد المستودع.
3. أضف نفس متغيرات البيئة الأربعة في **Project Settings > Environment Variables**.
4. Deploy. الموقع يعمل مباشرة لأن كل البيانات في Supabase (سحابي)، وليس في ملفات
   محلية — يصلح تمامًا لـ Vercel (بيئة serverless).

---

## 6. كيف تستعمل لوحة التحكم (بدون أي برمجة)

- **إضافة منتج**: لوحة التحكم ← المنتجات ← "إضافة منتج جديد" ← اختر الفئة، ارفع
  الصورة، اكتب الاسم والوصف بلغة واحدة فقط، ثم اضغط **"ترجمة تلقائية بالذكاء
  الاصطناعي"** لتعبئة اللغتين الأخريين تلقائيًا (يمكنك تعديلهما يدويًا بعدها من
  التبويبات)، ثم **حفظ**.
- **تعديل / حذف / إخفاء / إعادة ترتيب**: من جدول المنتجات، أزرار مباشرة لكل عملية.
- **الفئات**: تعديل الأيقونة والاسم والوصف بكل لغة (الفئات الست ثابتة لأنها تعكس
  أقسام المنتجات الفعلية، لكن يمكن إخفاء أي فئة مستقبلًا عبر إخفاء منتجاتها).
- **إعدادات الشركة**: الهاتف، واتساب، البريد، العنوان، الشعار، روابط التواصل
  الاجتماعي، ونص الصفحة الرئيسية (Hero) بكل لغة.

---

## 7. هيكل المشروع

```
src/
  app/
    [locale]/            الموقع العام (ar/fr/en) — الرئيسية، المنتجات، تفاصيل المنتج
    admin/                لوحة التحكم (محمية بتسجيل دخول Supabase Auth)
    api/translate/        مسار الترجمة الآلية عبر Claude (يتطلب ANTHROPIC_API_KEY)
  components/             مكوّنات مشتركة (Navbar, ProductCard, ImageUploader...)
  lib/
    supabase/             عملاء Supabase (client / server / admin)
    data/queries.ts        كل استعلامات القراءة العامة (Server Components)
  i18n/dictionaries.ts     نصوص واجهة ثابتة (أزرار، عناوين أقسام) — منفصلة عن محتوى المنتجات
  types/                   أنواع TypeScript المشتركة
supabase/
  schema.sql               مخطط قاعدة البيانات الكامل + RLS + Storage
  seed.sql                 بيانات أولية حقيقية (6 فئات + 61 منتجًا)
scripts/gen_seed.py         السكريبت الذي ولّد seed.sql (للمرجعية، غير مطلوب للتشغيل)
```

## 8. ملاحظات مهمة

- **الصور**: تُخزَّن في Supabase Storage (حاوية `product-images`) — تعمل بشكل
  كامل على Vercel وأي استضافة serverless (بخلاف التخزين على القرص المحلي الذي لا
  يبقى بين الطلبات).
- **البيانات المصدرية**: أسماء المنتجات الـ61 مستخرجة من كتالوج
  lounisagriculture.com العام، لكن الوصف والمميزات وطريقة الاستخدام أُعيدت صياغتها
  بالكامل بأسلوب FERTI SAFE. تركت حقل "المعلومات التقنية" لبعض المنتجات (كالنسب
  الدقيقة على الملصق الرسمي) عامًا حيث لم تتوفر بيانات مؤكدة من الصفحات العامة —
  يُنصح بمراجعتها وتدقيقها من الملصقات الرسمية للمنتجات قبل النشر النهائي، ثم
  تعديلها بسهولة من لوحة التحكم.
- **الفئتان "المغذيات النباتية" و"المكافحة البيولوجية"**: موجودتان في النظام
  (وفي التصنيف الظاهر للزوار) لكن بلا منتجات بعد، لأنه لم تتوفر منتجات فعلية
  لهما في المصدر وقت البناء — أضِف إليهما منتجات في أي وقت من لوحة التحكم.
